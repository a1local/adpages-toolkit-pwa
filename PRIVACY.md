# Privacy

The AdPages Toolkit PWA is designed to run entirely in the browser.

- It does not make network calls from the app logic.
- It does not collect analytics or telemetry.
- It does not require accounts, API keys, OAuth tokens, cookies, or passwords.
- It does not read browser history, contacts, files, location, or payment information.
- The service worker only caches the local app shell for offline use.

If hosted analytics, sync, accounts, or paid features are added later, this privacy document must be replaced before publication.
