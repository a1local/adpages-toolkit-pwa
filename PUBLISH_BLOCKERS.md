# Publish Blockers

- Deploy the static app to a real HTTPS URL.
- Validate installability in Chrome, Edge, and Windows.
- Generate final app icons, screenshots, short description, support URL, and public privacy URL.
- Run PWABuilder or equivalent Windows packaging checks.
- Test the packaged app on Windows before any Microsoft Store submission.
- Review Microsoft Store naming, claims, age rating, privacy, and support requirements.
- Do not submit to the Microsoft Store without explicit user confirmation.
